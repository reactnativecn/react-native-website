方法​

select()​

tsx
static select(config: Record<string, T>): T;

根据当前运行的平台返回最匹配的值。

参数：​

名称类型必填说明
configobject是详见下方配置说明。

select 方法返回当前运行平台最匹配的值。即如果你在手机上运行，android 和 ios 键会优先匹配。如果这两个键未指定，则会使用 native 键，最后才使用 default 键。

config 参数是一个对象，可包含以下键：

  • android (any)
  • ios (any)
  • native (any)
  • default (any)

使用示例：

tsx
import {Platform, StyleSheet} from 'react-native';

const styles = StyleSheet.create({
  container: {
    flex: 1,
    ...Platform.select({
      android: {
        backgroundColor: 'green',
      },
      ios: {
        backgroundColor: 'red',
      },
      default: {
        // 其他平台，例如 Web
        backgroundColor: 'blue',
      },
    }),
  },
});

上述代码会使容器在所有平台上都具有 flex: 1，在 Android 上背景为绿色，在 iOS 上背景为红色，在其他平台上背景为蓝色。

由于对应平台键的值可以是任意类型，select 方法也可以用于返回平台特定的组件，如下所示：

tsx
const Component = Platform.select({
  ios: () => require('ComponentIOS'),
  android: () => require('ComponentAndroid'),
})();

<Component />;
tsx
const Component = Platform.select({
  native: () => require('ComponentForNative'),
  default: () => require('ComponentForWeb'),
})();

<Component />;
