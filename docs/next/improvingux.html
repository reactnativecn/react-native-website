改进用户体验

配置文本输入​

在触屏手机上输入文本是一件有挑战性的事——小屏幕、软键盘。但根据你需要的数据类型，可以通过正确配置文本输入来简化这个过程：

  • 自动聚焦第一个输入框
  • 使用 placeholder 文本作为预期数据格式的示例
  • 启用或禁用自动大写和自动纠错
  • 选择键盘类型（例如 email、数字）
  • 确保回车键聚焦到下一个输入框或提交表单

查看 TextInput 文档 了解更多配置选项。

  • TypeScript
  • JavaScript

键盘弹出时的布局管理​

软键盘几乎会占据屏幕的一半空间。如果你有可能被键盘遮挡的交互式元素，请使用 KeyboardAvoidingView 组件 来确保它们仍然可以被访问。

  • TypeScript
  • JavaScript

使用 Android 水波纹效果​

Android API 21+ 使用 Material Design 水波纹效果，在用户触摸屏幕上的可交互区域时提供反馈。React Native 通过 TouchableNativeFeedback 组件 暴露了这一功能。使用这种触摸效果代替透明度或高亮，通常会让你的应用在平台上更加自然。不过需要注意的是，它在 iOS 或 Android API < 21 上不起作用，因此你需要在 iOS 上回退使用其他 Touchable 组件。你可以使用像 react-native-platform-touchable 这样的库来处理平台差异。

屏幕方向锁定​

除非你使用了 Dimensions API 且没有处理屏幕方向变化，否则多种屏幕方向默认应该可以正常工作。如果你不想支持多种屏幕方向，可以将屏幕方向锁定为竖屏或横屏。

在 iOS 上，在 Xcode 的 General 选项卡和 Deployment Info 部分中，启用你想要支持的 Device Orientation（确保在做更改时已从 Devices 菜单中选择了 iPhone）。对于 Android，打开 AndroidManifest.xml 文件，在 activity 元素中添加 'android:screenOrientation="portrait"' 以锁定为竖屏，或添加 'android:screenOrientation="landscape"' 以锁定为横屏。
